# 歸藏设计工作台移植版

基于 [op7418/dsh-guizang-design](https://github.com/op7418/dsh-guizang-design/tree/e275f1e4d4a81bd4875c251d33c643c242a8a8fd) 0.1.4 修改。上游许可见 LICENSE，各技能保留自己的许可和 skills/manifest.json 中的来源。本目录是独立扩展源码，可作为全局 catalog 开发包；未加入内置样例。

点击「开始创作」或「做同款」会打开当前项目的新建任务窗口，预填技能和草稿。作品文件保存在任务目录，作品库登记相对路径和宿主来源引用。点卡片可在右侧内置浏览器播放 HTML，点「继续修改」回到制作任务或项目侧栏。模板、脚本和双语官方示例随包提供。语气档案使用当前工作区的文章和用户主动提供的对话摘录。

普通网页渲染只需 Node。完整的 PDF、长图、卡片与字体子集导出还依赖上游 package.json 所列模块及浏览器。需要这些导出时，在工作区中复制本扩展到工具目录，在副本安装依赖并按技能说明运行脚本；避免在已审核的扩展包中安装依赖或写入产物。
